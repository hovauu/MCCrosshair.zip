# Прицел MC

Прицел поверх игры для Android (8.0+). Сам включается, когда открываешь Minecraft.

## Возможности
- 2 встроенных прицела (точка и крестик) + своя картинка (PNG)
- Цвет: готовые цвета, ползунки HSV, HEX
- Прозрачность, размер, положение (ползунки и кнопки −/+, «По центру»)
- Автозапуск: прицел появляется при входе в Minecraft и пропадает при выходе
- Мини-настройки в игре (кнопка у левого края экрана)
- Светлая и тёмная тема
- Прицел не мешает нажатиям

## Как собрать APK

### Вариант 1. Без компьютера (через GitHub)
1. Зарегистрируйся на github.com и создай новый репозиторий.
2. Загрузи туда все файлы проекта (Add file → Upload files). Папку `.github` тоже!
3. Открой вкладку **Actions** — сборка запустится сама (около 5 минут).
4. Открой завершённую сборку → внизу **Artifacts** → скачай `MCCrosshair-apk`.
5. Распакуй zip и установи `app-debug.apk`.

### Вариант 2. Android Studio
1. File → Open → выбрать папку `MCCrosshair`.
2. Дождаться синхронизации Gradle.
3. Build → Build App Bundle(s) / APK(s) → Build APK(s).
4. APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Первый запуск
1. Нажми START — приложение попросит включить службу «Прицел MC» в Специальных возможностях.
2. Если включить нельзя («Ограниченная настройка»): О приложении → ⋮ → «Разрешить ограниченные настройки».
3. Включи «Автозапуск в Minecraft».
4. На Xiaomi/Huawei/Samsung: в настройках приложения разреши работу без ограничений батареи,
   иначе система может выключать службу.

Пакет Minecraft: `com.mojang.minecraftpe`. Другие игры/лаунчеры можно добавить в Настройках (шестерёнка).
